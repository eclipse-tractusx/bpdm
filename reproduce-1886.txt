Issue #1886: Gate - Show Address Type Towards Site

Purpose
Reproduce the incorrect Gate output addressType without changing application code.
An address is the main address of Site A but an additional address of Site B.
The output for Site B incorrectly reports SiteMainAddress after Pool synchronization.

Environment
Pool Swagger: http://localhost:8080
Gate Swagger: http://localhost:8081
API version: v7 (observed on 7.6.0-SNAPSHOT)
Pool, Gate, Orchestrator and cleaning-service-dummy must be running.

Use new external IDs for a fresh run, or update the IDs below consistently.
BPNs are generated by the Pool. Replace placeholders with the BPNs returned
in your own output responses; do not reuse the observed BPNs for a fresh run.

RESULT
The incorrect final output was reproduced.
Site B's main address is Y (BPNA00000000037T), but the record naming Site B
and address X reports SiteMainAddress. X is only the main address of Site A.
The supplied responses captured the incorrect final output, not the
intermediate output transition from AdditionalAddress to SiteMainAddress.

Code location explaining the result:
bpdm-gate\src\main\kotlin\org\eclipse\tractusx\bpdm\gate\service\GoldenRecordUpdateServices.kt
GoldenRecordUpdateChunkService.update, line 418 in the inspected checkout:
businessPartner.postalAddress.addressType = addressProperties.addressType

The Pool type is global: an address is SiteMainAddress if any member site
uses it as its main address. Copying it does not account for the Gate
output's primary site.

No application code changes are required for this reproduction.
